Info & catatan performa

Video diproses frame-per-frame, jadi bisa makan waktu beberapa menit tergantung durasi.

Mode Shuttlecock, Gabungan, dan Posisi Lapangan manggil Roboflow lewat internet (panggilan API per frame untuk shuttlecock) — makin panjang video, makin banyak kredit API kepakai & makin lama prosesnya. Mode Gabungan & Posisi Lapangan juga menjalankan deteksi pose ViTPose di setiap frame, jadi termasuk paling lambat.

Untuk mode Posisi Lapangan di video, lapangan cuma dikalibrasi sekali (dari frame pertama, atau klik manual) lalu dipakai buat semua frame — kalau kamera bergerak/zoom selama video, posisinya bakal makin meleset di frame-frame berikutnya.

Klik 4 sudut lapangan manual untuk hasil paling akurat — kalau dilewati, sistem coba deteksi otomatis (kurang presisi di beberapa foto/video).

Mode TrackNetV3 jalan sepenuhnya lokal (nggak butuh API key/internet) dan manfaatin info gerakan antar-frame — lebih akurat buat kok yang kecil/blur dibanding mode Shuttlecock biasa, tapi cuma buat video dan lebih lambat di CPU (nggak ada GPU di server ini).

Mode Golf gabungin skeleton tubuh (ViTPose) dengan titik grip & head club golf (model publik Roboflow, deteksi per frame lewat API) — model club-nya dataset komunitas kecil, jadi kadang meleset di frame yang club-nya ketutup badan (awal backswing); confidence tiap titik ditampilkan biar kelihatan mana yang meragukan.

Buat video, ada slider "panjang video yang diproses" — geser di bawah 100% buat cuma proses bagian awal video (dipotong otomatis sebelum diproses), biar lebih cepat kalau nggak butuh video-nya diproses utuh.
